# Product Overview

Caide is built around strict project boundaries and immutable framework choices.

## Why Immutable Frameworks?

When you create a project in Caide, you lock in the framework at inception:

1. **React Native (Expo)** — Metro dev server, mobile simulator, browser preview for web, and native iOS/Android export.
2. **Flutter** — Dart toolchain, `flutter analyze`, DeviceLab simulator, and native APK/AAB/IPA builds.
3. **Website (Next.js / Vite)** — Fast SSR or SPA web apps with live hot-reloading browser preview and Vercel one-click deploy.
4. **Blank** — Minimal unconstrained directory where the agent designs custom architectures.

## System Requirements (Upcoming Desktop Builds)

When pre-packaged desktop releases arrive, the baseline system requirements will be:

- **Operating System**: macOS 13+ (Ventura or newer), Ubuntu 22.04+ / Fedora 38+ / modern Linux, or Windows 11 / Windows 10 (21H2+).
- **Memory**: 8 GB RAM minimum (16 GB recommended when hosting local Ollama model weights).
- **Disk Storage**: ~250 MB for the Caide desktop runtime and bundled utilities.
- **Node / Runtime**: Fully self-contained. The desktop shell embeds all required background execution runtimes without needing global dependencies installed on your system.

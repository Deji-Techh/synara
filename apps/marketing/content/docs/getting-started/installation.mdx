# Installing Caide

Caide is distributed as standalone desktop binaries for macOS, Linux, and Windows.

## Quick Install (macOS & Linux)

```bash
curl -fsSL https://caide.dev/install.sh | bash
```

## Manual Downloads

Visit the [Download Page](/install) to get native installers:
- **macOS**: Apple Silicon (`.dmg`) & Intel (`.dmg`)
- **Linux**: Portable AppImage (`.AppImage`) & Debian (`.deb`)
- **Windows**: Standard NSIS installer (`.exe`)

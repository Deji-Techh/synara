# React Native (Expo)

Caide treats React Native as a first-class citizen with deep Expo integration.

## Features

- Automatic Metro bundler supervision on port 8081.
- Responsive DeviceLab preview with iPhone and Android device framing.
- Physical device testing via integrated mobile QR codes.
- Native build pipelines with EAS or local Xcode / Android Studio.

# Caide Documentation

Caide is an open-source, local-first workspace for turning prompts into production full-stack software. It unifies chats, blueprints, tool execution, live device preview, and production builds into a single focused window.

## Core Features

- **Immutable Frameworks**: Start with Blank, React Native (Expo), Flutter, or Website (Next.js / Vite). Scaffolding, prompts, and build adapters adapt to your stack.
- **BYOK Multi-Model Hub**: Connect directly to Anthropic, OpenAI, DeepSeek, Google Gemini, Groq, or run completely offline with Ollama. Zero subscriptions or token markups.
- **App Blueprints & Surveys**: Review and approve architectural blueprints and state schemas before code generation begins.
- **LiveLab & DeviceLab**: Preview running applications across responsive mobile frames (iPhone, Android, Tablet, Desktop) with hot-reload and live console logs.
- **Neon Database Branching**: Instant copy-on-write database branches per thread for safe migration testing.

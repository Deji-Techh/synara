# Caide Documentation

Caide is an open-source, local-first workspace for turning prompts into production full-stack software. It unifies chats, architecture blueprints, tool execution, live multi-device previews, and production builds into a single focused window.

---

## Architectural Philosophy

Caide is engineered from the ground up to replace fragmented AI developer tools with an integrated local environment:

1. **V1 Faithful Engine + V2 High-Craft UI**: The agent turn engine, tool execution loops, consent gates, safeStorage encrypted credentials, and local SQLite persistence run with full fidelity, presented through a responsive, modern interface.
2. **100% Local-First Boundary**: Your code, git history, thread messages, and execution traces live strictly on your machine. Zero cloud telemetry, zero remote log tracking.
3. **True BYOK (Bring Your Own Key)**: Zero monthly subscription tiers, zero token markups, and zero artificial rate limits. Connect directly to frontier model providers (Anthropic, OpenAI, DeepSeek, Google Gemini, Groq) or run 100% offline with local Ollama instances.
4. **Immutable Framework Boundaries**: Stack selection is locked in at creation (React Native Expo, Flutter, Next.js / Website, or Blank). Toolchain verifiers, live dev servers, and prompts adapt specifically to your chosen framework.
5. **Architectural Alignment First**: Before destructive code modifications touch disk, Caide presents interactive App Blueprints and 3-question design surveys to align on technical tradeoffs.
6. **Live Multi-Device Stage**: Inspect running applications in real time with DeviceLab (iPhone 16 Pro, Google Pixel, iPad, Desktop) featuring hot reload, physical device QR codes, and live console streaming.
7. **Copy-on-Write Database Branching**: Connect Neon serverless Postgres to spin up isolated database branches per thread, allowing the agent to test schema migrations without jeopardizing staging data.

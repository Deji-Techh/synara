# Platform Patterns & Native Fidelity Skill Pack

## Cross-Platform Native Rules

1. **iOS Patterns**: Use SF Symbols, standard navigation bars, swipe-back gestures, and iOS system alert sheets.
2. **Android Patterns**: Use Material 3 tokens, dynamic color harmony, predictive back animations, and floating action button offsets.
3. **Web Patterns**: Fully responsive layout from mobile (390px) to desktop (1440px), clean URL routing, keyboard shortcuts.
4. **Haptics**: Subtle impact feedback on button taps, switches, and destructive confirmations.

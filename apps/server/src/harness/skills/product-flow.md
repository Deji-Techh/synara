# Product Flow & Spec Construction Skill Pack

## Flow Construction Rules

1. **Source of Truth**: Every app begins with `.caide/spec.md`.
2. **User Flows**: Define 3 to 5 core user journeys from entry to completion.
3. **Edge Cases**: Account for empty datasets, permission refusals, offline states, and server timeouts.
4. **Slice Partitioning**: Split large applications into 2 to 5 isolated slices that can each be independently built, verified, and merged.

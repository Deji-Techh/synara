# Anti-AI Slop & Quality Rubric Skill Pack

## Anti-Slop Directives

1. **No Generic Gradients**: Never use default purple-to-cyan or pink-to-blue background gradients. Use deep charcoal `#0D0D0D` with precise accent punches (`#E8493C`).
2. **No Placeholder Copy**: Never use "Lorem ipsum", "John Doe", or "Foo Bar". Use realistic, domain-specific names and engaging text.
3. **No Decorative Bloat**: Avoid stacking multiple frosted glass layers, neon glow borders, and floating background orbs that clutter the UI.
4. **Typography Precision**: Stick to clean, readable type scale hierarchies without random font sizing or washed-out low-contrast gray text.
